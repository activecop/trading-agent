## 🎯 Objetivo
Analisar métricas de mercado em tempo real da Coinbase e Binance, gerar sinais de trading e executar ordens em modo **PAPER TRADING** por defeito.

## 🛠️ Stack Tecnológica (100% Gratuita)
- **Backend:** Python 3.11 + FastAPI + APScheduler
- **Frontend:** Next.js (Vercel Free Tier) + Tailwind CSS
- **Base de Dados:** PostgreSQL (Supabase Free) ou SQLite local
- **Deploy:** Railway / Render (Free Tier)
